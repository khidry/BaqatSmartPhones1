طريقة تعديل العروض بدون إعادة تكويد التطبيق
=============================================

الطريقة 1 - Google Sheet (الأسهل، التحديث فوري)
1) افتح Google Sheets ← ملف ← استيراد ← ارفع data/offers.csv ← "استبدال ورقة العمل".
2) ملف ← مشاركة ← نشر على الويب ← اختر الورقة ← الصيغة CSV ← نشر ← انسخ الرابط.
3) افتح config.js وضع الرابط داخل sheetCsv:"..." ثم ارفع config.js على الاستضافة مرة واحدة.
بعدها أي تعديل أو إضافة عرض في الشيت يظهر في التطبيق تلقائيًا (قد يتأخر دقائق من جوجل).
لو الشيت تعطل التطبيق يرجع تلقائيًا لملف data/offers.json.

الطريقة 2 - ملف JSON على الاستضافة
عدّل data/offers.json وارفعه فقط (لا تغيّر أي ملف آخر). غيّر "updated" لتاريخ اليوم.

أعمدة الشيت (الصف الأول عناوين ولا يتغير):
company  = mobily / sawa / salam / friendi / virgin / libara / redbull / jawy / zain
category = cd (اتصال+بيانات) / fx (فليكس دولي) / dt (بيانات فقط) / vz (زوار)
name     = اسم الباقة (يمكن تركه فارغًا لباقات البيانات)
calls    = عدد الدقائق (مثل 1000) أو U لا محدود. أضف حرفًا بعد الرقم:
           a لكل الشبكات | o داخل الشبكة | i لكل الشبكات+دولي | l محلي ودولي
           مثال: 1000a  أو  Uo  أو  Uo+550  (و * لعلامة النجمة)
data     = البيانات بالجيجا (مثل 40) أو U لا محدود أو 1TB
social   = السوشيال بالجيجا أو U لا محدود، Us سناب وواتساب وفيسبوك لا محدود، Uc تواصل لا محدود
official = البيع الرسمي (رقم)
price    = سعر العرض (رقم)
validity = المدة: 1m شهر، 3m ثلاثة شهور، 2w أسبوعان، 14d أربعة عشر يومًا (أو فارغ)

ملاحظة: الشركات وألوانها وملاحظاتها (Notes) في data/offers.json فقط، والشيت يتحكم في العروض.

عند تعديل الكود: غيّر رقم الإصدار مرة واحدة في index.html (APP_VERSION وفي روابط ?v=) وسيظهر للمستخدمين زر/رسالة التحديث.

رفع الملفات على GitHub Pages (كلها بنفس الأسماء والمجلدات):
index.html, app.js, config.js, manifest.json, sw.js
icons/icon-192.png, icons/icon-512.png
data/offers.json, data/offers.csv
logos/mobily.png ... zain.png (تسعة ملفات)
